# Death World TD

**Co-op factory-building tower defence on a hostile alien world.**

Land beside the Nexus, strip the planet for ore, and build a factory that feeds your guns. Every ninety seconds the swarm comes for the Nexus, and each wave is bigger than the last. Build fast, defend smart, and hold out as long as you can, alone or with friends.

## Download

**[Download the latest version](https://github.com/molixatus/DeathWorldTD-releases/releases/latest)**: grab `DeathWorldTD.exe` and run it. There's no installer, and the game updates itself when you start it.

> **Windows SmartScreen:** the game isn't code-signed, so Windows may say it "protected your PC" the first time.
> Click **More info**, then **Run anyway**.

**Requirements:** Windows 10 or 11 (64-bit) and a graphics card with OpenGL 3.3, which almost any GPU from the last decade has.

## Features

- **Build a factory:** mine ore, smelt plates, run belts, inserters, assemblers, pipes and oil refineries, all in the spirit of Factorio.
- **Defend the Nexus:** gun, shotgun, flamethrower, cannon, rocket, mortar, sniper, tesla, laser and railgun turrets, plus walls, shredder walls, land mines, nukes and orbital strikes.
- **Research with Biomass:** every biter you kill drops Biomass for the team. Spend it to unlock new tech mid-fight.
- **Nine kinds of biter:** swarmlings, spitters, armoured carapaces, exploding bloaters and towering behemoths, which grow more common with every wave.
- **Co-op multiplayer:** host a game and friends join from the server browser. Each player picks a starting turret, and waves scale with the team.
- **Construction drones and blueprints:** copy, cut and paste whole sections of your base, and drones build them for you.
- **Command Archive:** earn Data Cores every run and spend them on permanent upgrades, plus helmets, building paint and suit finishes to show off to your friends.

## Playing together

1. One player clicks **Host co-op game**.
2. Everyone else opens the **Server browser** and joins, or uses **Direct connect** with the host's address.
3. The host picks a difficulty and starts the match from the lobby.

If friends can't see your game, forward **TCP port 27015** on your router, or join over a LAN or VPN such as Tailscale or ZeroTier.

## Controls

| Key | Action |
|---|---|
| W A S D | Walk |
| Mouse wheel | Zoom |
| 1 to 0 | Hotbar |
| Left click | Build / open a machine |
| Right click (hold) | Mine ore, trees and rocks / remove a building |
| R / Shift+R | Rotate |
| H / V | Flip a blueprint |
| E / Tab | Inventory and crafting |
| T | Research |
| Q | Pick the building under the cursor / clear the cursor |
| Ctrl+C / X / V | Copy / cut / paste a blueprint |
| Shift + click | Place a ghost for your drones to build |
| F | Pick items up off belts |
| Alt | Show what's inside machines |
| N | Call the next wave early |
| O | Orbital strike (once researched) |
| Esc | Menu |
